# dictionary from WordNet and from counted usage. These are written by hand

# try first, and a reading given 0 is possible but rare.

#   PRP pronoun       PRP$ possessive     WP WDT WP$ WRB the wh- words
#   NN NNS NNP nouns  JJ JJR JJS adjectives   RB RBR RBS adverbs
#   VB base verb  VBP am/are  VBZ -s form  VBD past  VBN participle  VBG -ing
#   POS the possessive 's
